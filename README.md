# MediBin Hero

A 3D browser game that teaches hospital bio-medical waste segregation: each waste item goes into the right colour-coded bin. English + தமிழ்.

**Play:** https://gowtham-raj-dev.github.io/medibin-hero/

## Run locally

```
npm install
npm run dev
```

Then open http://localhost:5173/.

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages (`.github/workflows/deploy.yml`).
