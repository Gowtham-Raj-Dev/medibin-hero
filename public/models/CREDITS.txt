3D MODEL CREDITS — MediBin Hero
================================

Every .glb file in this folder was downloaded from https://models.codelove.in/
(free 3D model library). Each file also carries its own licence in its glTF
"asset" block. The bins and the medical waste items that are not listed here
(syringe, gloves, blood tubes, cotton, mask, ...) are built in code and are
part of this game.
